Allow changes?

Query is read only until you say otherwise. With changes allowed, anything you run goes straight to this project:

  • INSERT, UPDATE and DELETE change rows, and there is no undo.
  • CREATE, ALTER and DROP change tables, and several statements can run at once.
  • The project saves itself on this device a moment later.

Download a copy first if you might want the data back. Tables that start with _qd_ stay protected, and the switch turns off again whenever you open a project.
